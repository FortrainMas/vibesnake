# VIBESNAKE

Психоделическая змейка на Electron: WebGL2-шейдеры (калейдоскоп, feedback-шлейфы, блум, хроматическая аберрация) и синтезированный саундтрек, который ускоряется вместе со змеёй.

```bash
npm install
npm start
```

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | рулить |
| Enter / Пробел | старт, реинкарнация |
| Пробел (зажать) | стрелять изо рта |
| Shift / E | сверхзаряд во все стороны (перезарядка 3.5 с) |
| 1–9 | скорость (очки умножаются на неё) |
| L | жизни: 1 / 3 / 5 / 9 / ∞ (в меню) |
| T или перетащить файл | добавить свой трек: BPM определяется сам, змея ходит в долю |
| N / B / Del | следующий трек / встроенный бит / убрать трек |
| P / Esc | пауза |
| V | уровень трипа: ЧИЛЛ → ТРИП → МАКСИМУМ |
| M | звук |
| F11 / Alt+Enter | фуллскрин |

## Правила

- Края поля — порталы, смерть только от своего хвоста и чёрных дыр.
- Ешь быстро подряд — растёт комбо-множитель.
- Каждые 5 сфер — новый уровень: быстрее, появляется чёрная дыра.
- Бонусы: гриб (трип, очки x2), кристалл (замедление), призрак (сквозь себя и дыры), звезда (+100, быстро исчезает).
